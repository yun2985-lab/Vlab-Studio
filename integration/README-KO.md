# VOID EYE + VLab Voice 0.41 안정성 수정 베타

- 이전 경기 음성 전사와 현재 경기 녹음을 분리했습니다. 종료된 녹음은 한 개씩 로컬 전사하고 새 경기 녹음은 바로 시작합니다.
- 녹화별 ID로 시작/종료 요청을 구분하며 중복 요청을 처리합니다. 이전 경기의 늦은 종료 요청은 새 녹음을 종료하지 않습니다.
- PC 연결 요청은 일시적인 연결 실패에 제한된 재시도를 적용합니다. 음성 요청 때문에 녹화 시작 스레드를 막지 않습니다.
- Host 재시작 시 저장된 녹음을 불러오고 중단된 전사를 대기열에 복구합니다. 비정상 종료된 표준 PCM WAV의 헤더를 실제 저장된 오디오 길이로 복구합니다. 디스크에 기록되지 않은 음성까지 복원하지는 못합니다.
- 방장 화면의 '이전 녹음 확인'에서 지난 녹음의 자막을 가져오거나 전사를 다시 요청할 수 있습니다. 동일 녹음 폴더의 Host 중복 실행을 차단합니다.

## 검증

기존 Voice/연결 테스트 및 추가 회귀 테스트: 연속 경기, 이전 종료 중복 요청, 녹음 종료 지연 중 다음 경기, 전사 중 재시작, WAV PCM 보존 복구, 중복 Host 차단. 로컬 WebRTC 5명/개별 트랙 시험 통과.
Windows 빌드 작업에서 설치·GUI 자동 Host 시작·로컬 모델 로드 검증 후 게시합니다. 실제 LoL 녹화, 서로 다른 네트워크의 5명 통화, 한국어 실음성 인식률·영상 싱크는 아직 실기기 확인 전입니다.

## 설치 및 제한

기존 VOID EYE를 종료하고 설치하세요. 설치 위치는 기존과 동일하며 로컬 모델을 포함합니다. 사용자 녹음은 LOCALAPPDATA/VLab Voice/recordings에 보관됩니다.
기본 연결은 같은 PC의 127.0.0.1입니다. 외부 참가자 접속은 신뢰할 수 있는 HTTPS와 별도 네트워크 구성이 필요하며 이번 수정에서 외부 접속을 완성한 것은 아닙니다.

제공 소스 ZIP은 0.39 원본 실행파일을 입력으로 사용하는 복구 빌드입니다. 전체 원본 녹화기 소스가 복원됐다는 의미가 아닙니다. 설치 파일과 소스의 커밋·SHA-256은 SOURCE-MANIFEST.json 및 SHA256SUMS.txt로 확인할 수 있습니다.

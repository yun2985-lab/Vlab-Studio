# VOID EYE + VLab Voice 0.40 실험 통합본

같은 설치 폴더에서 기존 VOID EYE 0.39와 VLab Voice Host를 시작합니다. VOID EYE 녹화 시작 직후 영상 인덱서의 `capture_clock`을 음성 녹음 시작 시각으로 보내고, 녹화 종료 시 음성 녹음을 마무리하여 화자별 WAV와 편집 가능한 자막 JSON을 생성합니다. 게임 중 STT를 수행하지 않습니다. Windows 설치 파일에 다국어 faster-whisper-small 로컬 모델을 포함합니다. PC 마이크 및 참가자 녹음은 브라우저에서 각각 명시적으로 동의한 사용자만 시작합니다. 작업실 버튼에서 방장 페이지가 열립니다. 팀 오브젝트 알림과 개인 음성 ON/OFF는 VLab Voice 페이지에서 제어합니다.

음성 호스트를 방장 PC에서 실행하는 모델입니다. 외부 PC/모바일 접속은 별도로 **기기에서 신뢰할 수 있는 HTTPS 인증서**와 네트워크 주소가 필요합니다. 기본 실행은 127.0.0.1 전용이므로 다른 기기는 그대로 접속할 수 없습니다. VOID EYE 0.39의 모든 원본 소스는 존재하지 않습니다. 이 소스 묶음은 사용자 배포 EXE를 기준으로 기존 bytecode를 보존하고 검증한 부분의 변경 소스를 합치는 재구성본입니다. 설치 파일과 동일한 통합 변경 소스와 재현 빌드 스크립트가 포함됩니다. 되돌릴 때는 기존 0.39 설치 파일을 별도로 보존하세요.

품질 게이트: Windows 설치/실행 및 모델 로드, 룸 자동 녹음, 3→5명 게임 실기기 통화, 영상 첫 프레임 대비 음성 오차, 실제 한국어 전사와 편집기 반입을 검증하기 전에는 출시 버전으로 간주하지 않습니다. VOID EYE 본체의 기존 녹화 기능이 오작동하거나 Voice 세션이 끊긴 경우 본체 녹화는 계속 진행하며 오류를 `%LOCALAPPDATA%\VLab Voice\bridge-errors.log`에 남깁니다.

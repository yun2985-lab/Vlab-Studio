# Vlab Studio

VOID EYE PC의 Windows 설치 파일을 배포하는 저장소입니다.

## PC 0.39 배포 안내

실행 파일과 업데이트 파일은 저장소의 Releases 영역에 보관합니다. README에는 다운로드 링크를 싣지 않습니다.

Windows x64용 전체 설치본입니다. 기존 설치 없이 사용할 수 있으며 Python 실행 환경, FFmpeg, FFplay와 클립 분석 의존성을 포함합니다. 녹화 영상 용량은 별도입니다.

## 설치와 사용

1. 실행 중인 VOID EYE를 종료합니다.
2. 위 Setup.exe를 실행합니다.
3. PC와 모바일에서 같은 Google 계정으로 로그인합니다.
4. 전체 영상에서 구간 선택 → 컷 추가 → 휴대폰으로 보내기를 사용할 수 있습니다.

기존 설치 경로를 사용하면 설정 및 녹화 파일을 보존하도록 구성되어 있습니다. 설치 경로를 바꾸면 기존 녹화 폴더를 다시 확인하세요.

## 0.39 변경

- NVIDIA GPU 인코딩 자동 검사 및 사용, 실패 시 CPU 재시도
- CPU 인코딩 스레드 조정, 준비된 클립 재사용
- 전체 영상 재생의 프레임 대기 및 미리보기 갱신 비용 감소
- Firebase 전송 상태 표시 및 cv2 전송 오류 수정 포함

## Android

Vlab Studio Android 앱은 Google Play 배포 예정입니다. 이 저장소에는 APK/AAB를 배포하지 않습니다. 스토어 링크는 출시 후 추가합니다.

## 배포 상태

시험 배포본입니다. Windows 빌드 머신에서 자동 설치와 설치된 배포 구성 파일의 SHA-256 대조를 통과했습니다. 사용자 GPU 성능, 대화형 재생과 실제 Firebase 수신은 별도 확인이 필요합니다. 코드 서명은 적용되지 않았습니다.

기존 0.31 실행 환경과 0.39 변경분을 합친 전체 설치본입니다. 대응 ZIP은 수정 모듈 및 재구성 스크립트를 담은 복구 소스이며 전체 원본 프로젝트는 아닙니다. 설치 빌드 방법은 installer/ 및 .github/workflows/package-pc-039.yml에 있습니다. GitHub 자동 생성 Source code ZIP은 설치파일이 아닙니다.

FFmpeg 등 포함 구성요소의 라이선스와 배포 정보는 설치 폴더의 안내 파일을 확인하세요.
